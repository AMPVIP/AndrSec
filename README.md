# AndrSec — Android Security System

[![Android](https://img.shields.io/badge/Android-8.0%2B-green.svg)](https://developer.android.com)
[![Kotlin](https://img.shields.io/badge/Kotlin-1.9-blue.svg)](https://kotlinlang.org)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**AndrSec** превращает старый Android-смартфон в умную охранную систему с удалённым управлением через VK.
Детекция движения и звука, отправка фото при тревоге, работа в фоне при выключенном экране — всё в одном приложении.

## ✨ Возможности

| Функция | Описание |
|---|---|
| 📷 **Детекция движения** | CameraX + ImageAnalysis. Настраиваемая чувствительность, кулдаун |
| 🔊 **Детекция звука** | AudioRecord. Порог в дБ, кулдаун от спама |
| 📸 **Фото при тревоге** | Автоматическая отправка в VK с retry (VK-серверы нестабильны) |
| 🎮 **Управление через VK** | Команды `статус`, `включить`, `снять`, `фото`, `батарея`, `помощь` |
| ⏱️ **Задержка 30 сек** | По кнопке — время выйти из кадра. По команде VK — мгновенно |
| 📊 **Статус + батарея** | Одна команда `статус` — состояние охраны + заряд/температура/напряжение |
| 🔋 **Foreground Service** | Работает при выключенном экране. Тип `dataSync` при снятой охране |
| 🌙 **WakeLock** | CPU не засыпает |
| 🔄 **Автозапуск** | После перезагрузки телефона |
| 🛡️ **Watchdog** | `WorkManager` перезапускает службу, если её убила система |
| 📝 **FileLogger** | Логи в файл — диагностика без ПК |
| ⚙️ **Настройки в приложении** | Токен и ID меняются без пересборки |

## 🎮 Команды бота

Напиши боту в личку VK:

| Команда | Синонимы | Действие |
|---|---|---|
| `статус` | `status` | Состояние охраны + батарея |
| `включить` | `вкл`, `on` | Включить охрану (мгновенно) |
| `снять` | `выкл`, `off` | Снять охрану |
| `фото` | `photo` | Снимок с камеры по запросу |
| `батарея` | `battery`, `заряд` | Только батарея |
| `помощь` | `help` | Список команд |

## 🚀 Установка

### Вариант 1. Скачать APK

1. Перейди в [Releases](../../releases)
2. Скачай последний `AndrSec-vX.X.apk`
3. Установи на телефон (разреши установку из неизвестных источников)
4. Открой приложение → **⚙️ Настройки** → заполни данные VK

### Вариант 2. Собрать из исходников

```bash
git clone https://github.com/AMPVIP/AndrSec.git
cd AndrSec
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## ⚙️ Настройка VK-бота

Нужен **токен сообщества** VK и **твой личный ID**.

### 1. Создай группу VK

1. VK → **Сообщества** → **Создать сообщество**
2. Тип: **Группа** (не «Публичная страница», не «Канал»)
3. После создания → **Управление**

### 2. Включи нужные настройки

| Раздел | Что включить |
|---|---|
| **Настройки → Разделы** | ✅ Сообщения |
| **Сообщения → Настройки** | ✅ Сообщения сообщества |
| **Настройки → Настройки для бота** | ✅ Возможности ботов |
| **Работа с API → Long Poll API** | ✅ Long Poll API + «Входящие сообщения» |
| **Работа с API → Ключи доступа** | Создать токен с правами `messages`, `manage`, `photos` |

### 3. Получи ID

- **`VK_GROUP_ID`** — ID группы. Из адреса `vk.com/club123456789` → `123456789`
- **`VK_ALLOWED_PEER`** — твой личный ID. Из адреса `vk.com/id123456789` → `123456789`

### 4. Введи в приложении

Открой AndrSec → **⚙️ Настройки** → заполни три поля → **Сохранить** → **Проверить**.

## 🧪 Использование

1. Установи приложение, выдай разрешения (камера, микрофон, уведомления)
2. Отключи **оптимизацию батареи** для AndrSec (Настройки → Приложения → AndrSec → Батарея)
3. Настрой бота VK (см. выше)
4. Нажми «Включить охрану» — отсчёт 30 сек → охрана включена
5. Поставь телефон на зарядку, закрепи на штативе
6. Управляй через VK

## ⚠️ Требования

- Android **7.0+**
- Разрешения: камера, микрофон, уведомления
- Отключённая оптимизация батареи
- Аккаунт VK

## 🛠️ Технологии

- **Kotlin** + **Coroutines**
- **CameraX** для камеры
- **AudioRecord** для микрофона
- **OkHttp** для HTTP
- **VK Long Poll API** для команд
- **Foreground Service** + **WakeLock**
- **WorkManager** для Watchdog
- **SharedPreferences** для настроек

## 📂 Структура проекта

```
app/src/main/java/com/example/andrsec/
├── MainActivity.kt          — главный экран, отсчёт 30 сек
├── SettingsActivity.kt      — настройки VK
├── GuardService.kt          — foreground service, камера/микрофон, команды
├── VkBot.kt                 — приём команд (Long Poll)
├── Notifier.kt              — отправка текста и фото в VK
├── VkPhotoUploader.kt       — загрузка фото в VK с retry
├── MotionDetector.kt        — анализ кадров на движение
├── SoundDetector.kt         — анализ звука (dB)
├── WatchdogWorker.kt        — перезапуск службы через WorkManager
├── BotSettings.kt           — хранение токена/ID
├── FileLogger.kt            — логи в файл (для диагностики)
├── BootReceiver.kt          — автозапуск после ребута
└── App.kt                   — Application, каналы уведомлений
```
